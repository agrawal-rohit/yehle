title: Available templates
description: Project types and starters you can generate with Yehle today.
---

Templates are **starters** under each language and project spec (for example `templates/typescript/package/basic`). Pick one when you run `yehle package --template <name>`.

<Cards>
  <Card title="TypeScript — Basic package" description="Minimal library with tests and standard tooling." href="/docs/available-templates/typescript-basic" />
  <Card title="TypeScript — React package" description="Package with a Vite + React playground." href="/docs/available-templates/typescript-react" />
</Cards>

More project types (for example monorepos or extensions) will appear here as they are added to the template registry.
